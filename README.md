 NovaMart Sales & Business Intelligence Analytics

A self-initiated Data Analyst portfolio project focused on retail sales, profitability, customer, product, category, and regional analysis.

 Project Overview

NovaMart is a realistic retail/e-commerce analytics project created to demonstrate an end-to-end Data Analyst workflow.

The project uses sales transaction data to identify business performance patterns and provide insights through Excel, SQL, and Power BI.

Project type:Self-initiated portfolio project using synthetic/realistic retail data.

Business Problem

NovaMart has transaction-level sales data but needs a centralized analytical solution to understand:

* Revenue and profitability
* Customer contribution
* Product performance
* Category performance
* Regional performance
* Monthly sales trends

 Tools & Technologies

* Excel — Data analysis and validation
* Power Query — Data cleaning and transformation
* SQL Server — Data analysis and business queries
* Power BI — Interactive dashboard and visualization

Project Workflow

Raw Sales Data → Data Cleaning → Excel Analysis → SQL Analysis → Power BI Dashboard → Business Insights

 Data Cleaning

The dataset contains **1,000 sales transactions**.

Data preparation included:

* Checking missing values
* Checking duplicate Order IDs
* Removing unnecessary spaces
* Standardizing text values
* Handling inconsistent city names
* Validating dates and numerical fields
* Documenting assumptions for missing values

Business Insights

The analysis was used to identify patterns in:

* Category sales and profitability
* Regional contribution
* Customer revenue concentration
* Product and sub-category performance
* Monthly sales and profit movement

These insights can support decisions around customer engagement, product focus, regional performance monitoring, and profitability improvement.
